# CudaText 日本語言語ファイル & プラグイン

修正したり追加した言語ファイルやプラグインを置いてます。</BR>
プラグインは日本語版です。

.po ファイルは CudaText で使用する際、.mo ファイルにコンパイルしてください。</BR>
PoEdit で開いて保存すれば .mo ファイルも出力されます。</BR>
コマンドの場合の例 : msgunfmt cuda_config_keys_ja.mo -o cuda_config_keys_ja.po</BR>
＊ gettext にパスを通してください。
