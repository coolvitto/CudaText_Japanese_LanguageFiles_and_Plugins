【2.1.9 / 2.1.13 の追加機能】
- 種類での絞り込み (ファイル系 / カーソル移動系 / クリップボード系 / 削除系 / 挿入系 / その他編集 / 検索系 / ウィンドウ系 / メニュー/マクロ / プラグイン / その他)
- Shift / Ctrl / Alt のチェックで、その修飾キーを含むホットキーだけを表示
- ホットキー欄でキーを押すと、そのキーの組み合わせを使っているコマンドを検索
    Backspace / Delete: 欄をクリア   Tab / Enter / Esc (単独): 通常の操作
- 一覧のダブルクリックで、ホットキーの設定ダイアログを開く
    ホットキー-2 の列ではホットキー-2、それ以外ではホットキー-1 (既存のホットキーは置き換え)
    連続ホットキーにしたいときは「設定/追加」ボタンを使う
- ホットキーの設定ダイアログ (2.1.10)
    現在のキー / 新しいキー (キー 1・キー 2) を表示し、新しいキー欄ではキーを押して入力
    空欄の欄は変更なし。Backspace/Delete で欄をクリア。削除は従来の「削除」ボタンを使う
    「設定/追加」ボタンでは、既存のホットキーの後ろに続けて入力 (連続ホットキー: A * B)
    すでに他のコマンドが使っているキーを入力すると「競合するキーがあります」の欄に
    そのコマンドと現在のキーを表示。そのコマンドの新しいキーも同じダイアログで設定できる
    (空欄のままなら、そのコマンドからそのキーを外す)
- ボタン (フィルター / すべて / リセット / ヘルプ) を 2 行目に移動
    すべて: 検索文字列・種類・修飾キーを解除   リセット: さらに並べ替えと OR も初期状態に戻す
- 「種類」の判定ルールは cd_keys_kind.py にあります
