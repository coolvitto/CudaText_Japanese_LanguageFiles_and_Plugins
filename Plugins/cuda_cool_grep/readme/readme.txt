Cuda Cool Grep
==============
ファイル内検索 (Grep) および置換を行うツールです。「秀丸エディタ」のスタイルを踏襲しています。

* 検索モードと置換モードは 1つのダイアログに統合されています。置換 >>または 検索 << ボタンを押して切り替えます。
* 設定は `settings/cuda_cool_grep.ini` に保存されます。
* 検索中に Esc キーを押すと、検索を中断できます。
* 検索結果（出力パネルまたは結果タブ）の行をダブルクリックすると、該当するファイルへジャンプします。
* 日本語化: `cuda_cool_grep_ja.zip` をインストールしてください (`data/langmenu` および `data/langpy` フォルダーが含まれています)。
